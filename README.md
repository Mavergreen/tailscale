# Tailscale for Mavericks

Tailscale
([open-source edition](https://github.com/tailscale/tailscale))
for Mac OS X 10.9 Mavericks.

## How to use

From the menu, log into your account and join the machine to your tailnet.
Or if you prefer the CLI, `tailscale up`.
`tailscaled` will automatically reestablish the link at boot.
