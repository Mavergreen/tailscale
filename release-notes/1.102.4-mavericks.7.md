- **Exit nodes now work.** Choose one with `tailscale set --exit-node=<node>` (or from the menu
  bar's Exit Nodes menu), and your IPv4 traffic leaves through it. The menu bar icon shows when
  one is in use.
- **Your local network is blocked while an exit node is on**, as on other platforms. Allow it
  with `tailscale set --exit-node-allow-lan-access` (the menu bar has no toggle for this yet).
- **Turning an exit node off no longer disconnects your Mac.** Before, it could delete the Mac's
  own network routes and leave it offline until a restart.
