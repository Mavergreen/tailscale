Standalone, self-updating Tailscale for Mac OS X 10.9.5 Mavericks.

- Tailscale **1.98.8** (upstream) built with the Mavergreen go126 toolchain: x86_64,
  minimum-10.9, no post-10.9 imports (compat-gated).
- Ships the `tailscaled` daemon (LaunchDaemon), the `tailscale` CLI, and the menu-bar app
  (LaunchAgent), plus a Sparkle auto-updater that keeps this install current.
- Trust model is baked into the toolchain (system keychain ∪ Go's bundled roots); no per-app
  TLS patch.

This is an **unofficial community build of Tailscale for Mac OS X 10.9**, packaged by
Mavergreen — not affiliated with or endorsed by Tailscale Inc. It is the upstream
Tailscale client with only 10.9 build/compatibility shims; report Mavericks-specific issues
to Mavergreen, not to Tailscale.

First Mavergreen release.
